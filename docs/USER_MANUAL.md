# 使用者操作手册

这份手册按页面说明系统怎么用。每一节都写了“谁能做”“怎么做”“做完会发生什么”。

## 角色速查

| 角色 | 主要职责 |
| --- | --- |
| 系统管理员 | 初始化系统、维护账号、查看运维和全局设置 |
| 总部管理员 | 监管各分支进度、查看报表、处理总部侧管理事项 |
| 总部工作人员 | 查看总部监管数据，通常以只读为主 |
| 分支管理员 | 管理本分支计划、考生、审核、节点和业务闭环 |
| 分支工作人员 | 维护意向考生、报名资料和日常考务信息 |

如果页面上没有某个按钮，通常说明你的角色不能执行该操作。

## 今日工作台

谁能看：登录用户。

用来做什么：

- 查看当前最需要处理的待办。
- 查看计划阶段、逾期节点、最近动态。
- 快速跳到对应页面继续处理。

怎么用：

1. 登录后默认进入“今日工作台”。
2. 先看“优先待办”。
3. 有待办时，点击卡片或按钮进入对应页面。
4. 没有待办时，可以进入“意向考生”或“考评计划”准备下一批业务。

## 意向考生

谁能用：分支管理员、分支工作人员。

用来做什么：

- 记录咨询人员或潜在报名人员。
- 后续把合适的人转为正式考生。

新增意向考生：

1. 点击左侧“意向考生”。
2. 点击“新增意向考生”。
3. 填写姓名和手机号。
4. 选择意向职业、工种和等级。
5. 可填写来源和备注。
6. 点击保存。

编辑意向考生：

1. 在列表找到该人员。
2. 点击“编辑”。
3. 修改信息后保存。

转为正式考生：

1. 确认已有已发布计划。
2. 在意向考生列表点击“转正式”。
3. 选择考评计划。
4. 补身份证号、性别、文化程度等基础字段。
5. 点击确认。
6. 转换后，到“报名资料”继续补齐 33 项报名资料。

注意：

- 重复手机号允许保存，系统会提示你先核对是否同一人。
- 报名阶段结束后的计划不能再转入正式考生。
- 草稿计划不能接收正式考生。

## 考评计划

谁能用：分支管理员为主；其他角色按权限查看。

用来做什么：

- 创建考试计划。
- 发布计划，让计划进入正式流程。
- 回退或取消计划。

新建草稿：

1. 点击“考评计划”。
2. 点击“新建草稿”。
3. 填写计划名称、职业、职业工种名称、等级、考试日期、报名截止日期、考试地点和人数上限。
4. 点击保存草稿。

发布计划：

1. 确认草稿信息无误。
2. 在计划列表点击“发布”。
3. 系统会自动完成“制定计划”节点，并让“考试报名”节点进入进行中。

编辑计划：

1. 只有草稿计划可以编辑。
2. 点击“编辑”，修改后保存。

回退计划：

1. 已发布计划如需调整，点击“回退”。
2. 回退会把该计划下正式考生转回意向考生，并移除正式考生记录。
3. 操作前请确认，避免影响正在处理的报名资料。

取消计划：

1. 只有草稿计划可以取消。
2. 必须填写取消备注。
3. 有正式考生的计划不能直接取消。

## 报名资料

谁能用：分支管理员、分支工作人员；系统管理员可补录资料但看不到缴费字段。

用来做什么：

- 维护正式考生的 33 项报名字段。
- 勾选材料清单。
- 上传证件照。
- 审核报名资料。
- 导出资料包给当地上级部门业务系统。
- 回填已经上传当地系统的状态。

选择计划：

1. 点击“报名资料”。
2. 先在顶部选择一个已发布计划。
3. 页面才会加载该计划下的正式考生。

新增正式考生：

1. 选择已发布计划。
2. 点击“新增考生”。
3. 填写报名字段和材料。
4. 保存。

维护考生资料：

1. 在考生列表点击“资料”。
2. 补齐 33 项字段。
3. 勾选已收齐的材料。
4. 上传证件照。
5. 保存。

审核：

1. 分支管理员确认资料完整。
2. 点击“通过”或“驳回”。
3. 驳回后，正式考生会回到意向考生跟进池。

导出资料包：

1. 选择计划。
2. 确认可导出人数不为 0。
3. 点击“导出资料包”。
4. 下载后上传到当地上级部门业务系统。

上传回填：

1. 当资料已上传到当地上级部门业务系统后，点击“上传回填”。
2. 填写备注。
3. 如果确认报名阶段结束，选择结束考试报名节点。
4. 结束后不能继续新增正式考生或意向转正式。

## 节点追踪

谁能用：分支和总部按权限查看；分支管理员执行部分节点动作。

用来做什么：

- 查看每个计划的 9 个节点进度。
- 处理逾期或进行中的节点。

怎么用：

1. 点击“节点追踪”。
2. 选择或查看当前计划。
3. 看节点状态：待开始、进行中、已完成、逾期。
4. 对允许线下确认的节点，按页面按钮完成。
5. 对业务节点，回到对应业务页面处理，例如报名资料、成绩管理、证书管理。

## 成绩管理

谁能用：分支和总部按权限使用。

用来做什么：

- 录入理论、实操、综合评审等成绩。
- 系统计算是否合格。
- 复核成绩。

基本步骤：

1. 点击“成绩管理”。
2. 选择计划。
3. 录入或导入成绩。
4. 检查系统判定的合格状态。
5. 按流程复核。

## 证书管理

谁能用：分支证书经办、总部审核或监管人员。

用来做什么：

- 为合格考生生成或导入证书编号。
- 管理证书打印、发放、作废、补发和销毁。

基本步骤：

1. 点击“证书管理”。
2. 按页面中的库存、打印、发放、作废等模块操作。
3. 上传或导入文件时，只使用系统允许的文件格式。
4. 出现库存或数量提醒时，先核对纸质证书和系统数量是否一致。

## 档案管理

谁能用：分支和总部按权限使用。

用来做什么：

- 生成认定批次档案。
- 查看档案哈希、文件大小和归档状态。

基本步骤：

1. 点击“档案管理”。
2. 选择符合条件的计划或批次。
3. 生成归档材料。
4. 核对归档结果。

## 系统设置

谁能用：系统管理员、总部管理员、分支管理员按权限使用。

常见设置：

- 账号管理：创建、停用、重置密码。
- 提醒设置：配置提醒策略。
- 工作日历：维护节假日和调休工作日。
- 备份设置：配置备份策略。
- 打印模板：调整证书或表格模板。

账号管理注意：

- 不删除历史账号，离职或停用通过状态控制。
- 新建账号或重置密码时，临时密码至少 12 位，并同时包含大写字母、小写字母、数字和特殊字符。
- 临时密码不能包含用户名，避免被猜到。
- 设置临时密码后，必须线下安全告知本人。
- 不要在公开聊天或文档里发送密码。

## AI 运维

谁能用：系统管理员。

用来做什么：

- 查看系统健康状态。
- 创建备份。
- 下载迁移包。
- 查看近期日志。

常用操作：

1. 进入“AI 运维”。
2. 先看健康状态是否正常。
3. 需要备份时点击备份。
4. 需要迁移时导出迁移包。
5. 下载的备份包和迁移包必须妥善保存，不要公开传播。

## 常见问题

### 为什么我看不到“意向考生”

你可能不是分支管理员或分支工作人员。请联系管理员确认角色。

### 为什么计划不能取消

只有草稿计划可以取消，而且必须没有正式考生，还要填写取消备注。

### 为什么不能新增正式考生

请确认：

- 已选择已发布计划。
- 计划的考试报名节点还没有结束。
- 你有新增考生权限。

### 为什么导出资料包人数是 0

通常是因为考生资料还不满足导出条件。请检查：

- 33 项必要字段是否完整。
- 材料是否齐全。
- 是否已经审核通过。
- 证件照是否已上传。

### 为什么总部看不到缴费状态

缴费状态属于分支私有信息。总部监管报表不会展示缴费字段，这是系统权限设计。
