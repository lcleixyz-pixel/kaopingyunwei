# 使用者快速入门

这份说明给第一次使用系统的人看。你不需要懂技术，只要按页面按钮一步一步操作。

## 这套系统是做什么的

本系统用于总部和分支机构内部管理职业技能等级认定考务流程。

简单说，它帮你做这些事：

- 先登记意向考生，等计划合适时转为正式考生。
- 创建考评计划，并自动生成 9 个考评节点。
- 整理正式考生报名资料和材料清单。
- 审核报名资料，导出给当地上级部门业务系统使用的报名表。
- 回填“已经上传当地系统”的状态。
- 跟踪成绩、证书、档案和节点进度。
- 让总部看到各分支进度，但不查看分支私有缴费信息。

它不替代当地上级部门业务系统。当地系统仍然照常使用，本系统负责内部整理、提醒、留痕和报表。

## 登录前准备

请向管理员确认 3 件事：

- 系统访问地址，例如 `https://你的域名`。
- 你的用户名。
- 你的初始密码。

文档不会写固定默认密码。密码应由初始化环境变量、管理员或密码管理器提供。

## 第一次登录

1. 打开系统地址。
2. 在“用户名”输入你的账号。
3. 在“密码”输入管理员给你的密码。
4. 点击“登录”。
5. 如果登录失败，先检查用户名和密码是否复制错了。
6. 如果连续失败多次，系统可能临时限制登录。请稍后再试，或联系管理员解锁/重置密码。

## 你会看到哪些菜单

不同角色看到的菜单不一样，这是正常的。

| 菜单 | 谁常用 | 做什么 |
| --- | --- | --- |
| 今日工作台 | 所有人 | 看待办、风险、最近动态 |
| 意向考生 | 分支管理员、分支工作人员 | 维护潜在报名人员 |
| 考评计划 | 分支管理员 | 新建、发布、回退、取消计划 |
| 报名资料 | 分支管理员、分支工作人员 | 维护正式考生 33 项报名字段和材料 |
| 节点追踪 | 分支和总部 | 看 9 个节点进度 |
| 成绩管理 | 分支和总部 | 录入、复核和查看成绩 |
| 证书管理 | 分支和总部 | 证书编号、打印、发放、作废等 |
| 档案管理 | 分支和总部 | 生成和查看归档材料 |
| AI 运维 | 系统管理员 | 备份、健康检查、迁移包 |
| 系统设置 | 管理员 | 账号、提醒、工作日、备份、模板 |

## 最常见的一条业务流程

如果你是分支工作人员或分支管理员，通常按这个顺序操作：

1. 进入“意向考生”，新增或维护咨询报名人员。
2. 进入“考评计划”，由分支管理员新建草稿计划。
3. 确认计划信息无误后，发布计划。
4. 回到“意向考生”，把符合条件的人转为正式考生。
5. 进入“报名资料”，选择已发布计划。
6. 打开考生“资料”，补齐 33 项报名字段和材料勾选。
7. 分支管理员审核通过。
8. 点击导出资料包，下载报名表和材料包。
9. 在当地上级部门业务系统上传。
10. 上传完成后，回到“报名资料”，点击“上传回填”。
11. 如果报名阶段确实结束，确认结束“考试报名”节点。
12. 后续在“节点追踪”“成绩管理”“证书管理”“档案管理”继续处理。

## 页面提示怎么看

系统里的中文提示通常分 3 类：

- 蓝色或绿色提示：操作成功或状态正常。
- 黄色提示：需要注意，例如重复手机号、临近截止、库存偏低。
- 红色提示：操作失败或权限不足，需要按提示修正。

如果你看到英文错误、乱码、白屏或页面一直转圈，请截图并联系管理员。

## 分页怎么用

当数据很多时，页面底部会出现分页。

- 点击“下一页”查看后面的数据。
- 点击“上一页”返回前一页。
- 搜索、筛选或切换计划后，系统会自动回到第 1 页。
- 如果数据不多，分页按钮不会显示，这是正常的。

## 不要做的事

- 不要把账号密码发到微信群、公开文档或截图里。
- 不要把系统导出的备份包、迁移包、数据库文件发给无关人员。
- 不要在不确认的情况下结束“考试报名”节点。结束后不能继续新增正式考生，也不能把意向考生转正式。
- 不要在当地上级部门业务系统未同步前，随意修改已审核通过的考生资料。

## 遇到问题先这样处理

| 现象 | 先做什么 |
| --- | --- |
| 登录失败 | 检查用户名、密码、租户/机构是否正确 |
| 提示没有权限 | 确认你是否用错账号，或请管理员调整角色 |
| 看不到某个菜单 | 你的角色可能没有该功能权限 |
| 找不到某个考生 | 检查是否选了正确计划、状态筛选或分页 |
| 无法转正式 | 确认计划已发布，且考试报名节点没有结束 |
| 无法新增正式考生 | 先选择已发布计划，确认报名阶段仍开放 |
| 导出失败 | 检查考生资料、材料、审核状态是否满足要求 |
| 页面卡住 | 刷新页面；仍不行就截图给管理员 |
